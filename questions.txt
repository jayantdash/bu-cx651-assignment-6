(1) The time command shows how long the grep program took to run. It took 0.031 seconds of real time, 0.015 seconds of user CPU time, and 0.012 seconds of system CPU time. The program Found 207 of help in data/warnpeace.txt.
(2) I did not observe any data races. Each worker receives its own argument structure and uses its own file handle, line buffer, and local count or result structure. The main thread waits for all workers with pthread_join before combining their results, so the results are not modified concurrently and no mutex is needed.
(3) The pthread version manually creates and joins threads, then collects each worker's result. The OpenMP version uses a parallel for directive, so the runtime schedules the chunk iterations without explicit thread creation or joining. Each iteration writes to its own result slot, and the main thread combines the slots after the loop.
